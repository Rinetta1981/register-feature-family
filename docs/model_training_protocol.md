# Model Training Protocol

## Status

Development protocol version 0.1.

This protocol is defined after dataset v0.1 was frozen and before
training-result inspection.

## 1. Research purpose

The synthetic model is intended to answer:

> Does a transformer represent linguistic register as one general
> formal–informal direction, or as a family of causally separable
> features?

The small transformer is therefore an experimental object rather than a
language model intended for general-purpose performance.

The initial goal is to learn the frozen synthetic task reliably enough
to justify later mechanistic analysis.
