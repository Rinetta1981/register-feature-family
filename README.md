# Register Is a Feature Family, Not a Dial

## Research question

Does a transformer language model represent linguistic register as one
general formal–informal direction, or as a family of causally separable
features?

The initial study focuses on:

- lexical formality;
- syntactic directness;
- politeness mitigation;
- epistemic stance;
- speaker–addressee power relations.

## Project design

The project will proceed in two stages:

1. Train and interpret a small transformer using a synthetic language
   with known sociolinguistic variables.
2. Test whether the central findings transfer to an open pretrained
   language model.

## Current status

**Phase 1: research design and repository setup.**

No empirical conclusions have been reached.

## Planned evidence

The study will compare:

- a single formal–informal representation;
- multiple supervised feature directions;
- sparse autoencoder features;
- causal interventions on candidate representations;
- one focused circuit for a register-related computation.

## Reproducibility

The repository will include typed Python, automated tests, continuous
integration, experiment configurations, data manifests, and documented
reproduction commands.
